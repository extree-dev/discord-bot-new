Политика конфиденциальности

Extree — бот модерации для Discord и его сайт (extree.tech, bot.extree.tech). Эта страница объясняет, какие данные собираются при использовании бота и личного кабинета, зачем они нужны и как ими распорядиться.

Какие данные собираются

При входе в личный кабинет через Discord (OAuth2):

  • Discord ID, имя пользователя и аватар — чтобы показать, кто вошёл;
  • список серверов, на которых состоит аккаунт, — чтобы определить, на каких из них есть права администратора и показать только их в кабинете.

Эти данные не сохраняются отдельно: они запрашиваются у Discord заново при каждом входе и живут только в рамках сессии (сессионная кука, см. ниже).

При работе бота на сервере:

  • Модерация — предупреждения (варны) с причиной и ID модератора, история наказаний, настройки automod/raid shield/anti-nuke — привязаны к Discord ID участника и ID сервера, хранятся в базе данных бота, пока функции модерации нужны серверу;
  • Тикеты поддержки — ведутся как обычные каналы/треды в самом Discord, под контролем администрации конкретного сервера, а не в отдельной базе бота;
  • Активность участников — счётчики сообщений и времени в голосовых каналах для системы уровней, привязаны к Discord ID участника и ID сервера;
  • Журнал аудита — если администратор сервера включил эту функцию, короткие выдержки удалённых/изменённых сообщений публикуются в канал-журнал на самом сервере; это решение и данные принадлежат администрации сервера, не Extree.

Бот не хранит переписку целиком. Текст сообщения анализируется автомодерацией в момент отправки (проверка на спам/ссылки/капс) и не сохраняется, кроме случаев журнала аудита выше.

Файлы cookie:

Сайт кабинета (bot.extree.tech, extree.tech) использует одну сессионную куку (extree_session) — она хранит факт входа через Discord, помечена HttpOnly и Secure, не читается скриптами на странице и не используется для рекламы или трекинга между сайтами.

Как используются данные

Все перечисленные данные используются исключительно для работы функций бота и кабинета: модерация, тикеты, система уровней, настройки сервера. Данные не продаются и не передаются третьим лицам — за исключением Discord, через API которого бот и работает.

Хранение и удаление

Данные сервера (варны, настройки, активность) хранятся, пока бот состоит на этом сервере. При удалении бота с сервера или по запросу администрации сервера данные можно удалить — напишите через issue в репозитории проекта с указанием ID сервера.

Дети

Extree — надстройка над Discord и не предназначена для лиц, которым запрещено пользоваться самим Discord согласно его условиям использования.
